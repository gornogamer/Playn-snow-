### 🎮 Features
- ⛄ **Interactive Snowfield & Physics**: Ballistic parabolic snowball throwing, deep snow footprints, and aurora borealis sky.
- 🎅 **Santa Claus & Flying Sleigh**: Animated Santa NPC with interactive snowball reactions, toggleable Santa Hat/Suit, Magic Snowballs with golden sparkle trails, and a flying reindeer sky flyby!
- 🎨 **Modular Snowman Builder**: 3-tier sculpting studio with custom hats, twig arms, carrot noses, and persistence.
- 🎯 **Snowball Target Range**: Floating target bells with procedural chimes and accuracy tracking.
- 🎁 **Frost Crate Depot**: Integrated with Rare Friends ($RF) contract rewards.
